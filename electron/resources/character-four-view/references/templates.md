# 版式模板：T1-T4 骨架

**使用规则**：

1. 骨架一字不改，只填 {花括号} 槽位；槽位词从 intake.md 的锁里逐字取，锁外特征不新增。
2. 每个版式自带防漂移三重约束（§1），编译时不得删减。
3. 视图顺序与格数不得调换——下游句式（usage.md）按固定格序引用（如 2.0 替代方案按「格4=头部、格1=全身」裁切）。
4. 不即兴发明新版式；确需变化只用 §6 变体参数。每个版式的语料出处见 §8。

---

## 1. 防漂移三重约束（所有版式共用）

| # | 约束 | 位置 |
|---|---|---|
| 1 | 全局句「同一人物同一服装同一光线；格1-3 为同一无头身体，格4 为同一人的面部」 | 首句 |
| 2 | 权威格声明「面部唯一事实源为格4（头部特写）」 | 面部句尾 |
| 3 | 禁止项「格1-3 出现头部或面部、多个头、格4 与身体肤色不符、格间服装差异、动态姿势、文字水印」 | 末句 |

原理：设定图最高频的失败是「小图四张脸」与「多头」。无头版式把身体小图里的脸直接移除（漂移源消灭而非约束），面部只在大比例特写格里出现一次；禁止项封住已知失败模式。（来源：官方 FAQ 双胞胎问题 + asset-first §3.1 + 老李无头三栏实证 + 2026-09-12 用户实测反馈）

## 2. T1 标准四视图（默认；视频参考 / 通用人设）

适用：短剧管线 sheet 槽、Seedance / 即梦参考、通用人设。**无头版（默认）**——小图里的脸是漂移源且像素浪费：格 1-3 只保留身体事实，面部唯一事实源收拢到格 4 特写（2026-09-12 按用户实测反馈从含头改为无头）。

```text
角色设定图（character sheet），同一人物同一服装同一光线，四格横向并排：
格1——无头全身正面站姿（颈部平整截断，展示全身比例与剪裁）
格2——无头全身侧面站姿（右侧 90°，颈部平整截断，展示侧面轮廓与剪裁）
格3——无头全身背面站姿（颈部平整截断，展示服装背面与背部剪裁）
格4——头部五官正面特写（大比例，神情沉静，含发型正面，面部细节权威）
画幅 16:9，纯浅灰无缝背景，均匀柔光无强投影，全身完整不裁切，四格比例一致。
体型：{身高体型}。服装：{6 项锁 + 鞋履}，全身完整展示剪裁。
面部（格4 为唯一事实源）：{五官 10 项锁}，{标志性特征}。发型：{发型 5 项}。
风格：{题材-风格映射}，细节锐利。
禁止：格1-3 出现头部或面部、多个头、格4 与身体肤色不符、四格间服装差异、动态姿势、文字水印。
```

要点与取舍：无头消除了「小图四张脸」这一最高频失败模式，代价是侧面/背面的发型与头饰不再展示——发型由格 4 + 发型 5 项锁承担；确需各视角发型展示时走 §6 含头变体。格 1-3 的颈部截断是版式预期，QC 不视为裁切。

## 3. T2 紧凑三栏无头（无侧面视图需求时）

适用：不需要侧面轮廓的紧凑场景（正/背已够用的视频参考）。与 T1 同一无头思想的老李原版三栏；需要侧面轮廓（3D、走位参考）时用 T1。

```text
角色设定图（character sheet），同一人物同一服装同一光线，三栏横向并排：
栏1——无头全身正面站姿（颈部平整截断，展示全身比例与剪裁）
栏2——无头全身背面站姿（颈部平整截断，展示服装背面与背部剪裁）
栏3——头部五官正面特写（大比例，神情沉静，面部细节权威）
画幅 16:9，纯白无缝背景，均匀柔光无强投影，全身完整不裁切，三栏比例一致。
体型：{身高体型}。服装：{6 项锁 + 鞋履}，全身完整展示剪裁。
面部（栏3 为唯一事实源）：{五官 10 项锁}，{标志性特征}。发型：{发型 5 项}。
风格：{题材-风格映射}，细节锐利。
禁止：多个头、栏3 面部与身体肤色不符、动态姿势、文字水印。
```

## 4. T3 经典 turnaround（3D 建模 / 模型资产 / 通用）

适用：3D 建模底稿、游戏资产、需要 3/4 视图的通用 turnaround。英文出货（MJ / GPT-image 友好）；3D 绑定用途把站姿换 T-pose（§6）。

```text
Character reference sheet, turnaround model sheet of one character, clean neutral gray studio background, soft even studio lighting, full body front view, side profile view, and 3/4 view of the same character side by side, {style keywords}, consistent facial features and proportions across all views, {skin or material detail}, high detail, single character only, no text, no watermark.
Character: {age and gender and build}. Face: {10 face locks}. Hair: {5 hair locks}. Outfit: {6 outfit locks and footwear}.
```

## 5. T4 参考图四视图（照片转人设 / 旧角色重制）

适用：用户给了人物照片或旧设定图，要重排出标准四视图。核心是「职责声明 + 版式防泄漏」：参考图只提供人，不提供拍法。

```text
【参考图职责】@图片1 定义该角色的长相、发型与服装，是唯一人物参考。
【生成目标】@图片1 这个人的角色设定图（character sheet），同一人物同一服装同一光线，四格横向并排：格1 无头全身正面站姿（颈部平整截断）、格2 无头全身侧面站姿（右侧 90°，颈部平整截断）、格3 无头全身背面站姿（颈部平整截断）、格4 头部五官正面特写（大比例，含发型正面，面部细节权威）。
【版式】画幅 16:9，纯浅灰无缝背景，均匀柔光无强投影，四格比例一致，全身完整不裁切；格1-3 为同一无头身体，面部唯一事实源为格4。
【一致性】服装、配饰、发色与@图片1 完全一致，不得增删；脸型五官与@图片1 一致。
【禁止】复制@图片1 的拍摄姿势、背景、光线和构图；格1-3 出现头部或面部；多个头；四格间服装差异；动态姿势；文字水印。
```

多张参考图时按职责逐份声明（cn 附录 B #214 句式）：@图片1 定义长相，@图片2 定义服装，@图片3 定义风格——每张一个职责，不重复指派。

## 6. 变体参数（不改骨架，只换对应行）

| 参数 | 取值 | 默认 |
|---|---|---|
| 画幅 | 16:9 横排 / 1:1 四宫格 | 16:9 |
| 头部 | 无头（默认）/ 含头（**仅用户明确要求时**启用，agent 不得自行升级） | 无头 |
| 站姿 | 自然站姿 / T-pose（3D 绑定） | 自然站姿 |
| 底色 | 纯浅灰（T1/T4）/ 纯白（T2）/ 中性灰棚拍（T3） | 按版式 |
| 风格 | §7 映射表 / 用户指定 | 按题材 |
| 服装状态 | 主服装 / 状态变体 | 主服装（变体 = 新资产 `CHR-{角色名}-{状态}`） |

**含头变体替换行**（只换 T1 骨架的格 1-3 三行与禁止项首条，其余不动）：

```text
格1——全身正面站姿（含头，展示发型正面）
格2——全身侧面站姿（右侧 90°，含头，侧脸轮廓清晰）
格3——全身背面站姿（含头，展示发型背面与服装背面）
```

禁止项首条「格1-3 出现头部或面部」改为「四格间面部/发型/服装差异」，面部句改回「四格为同一张脸，面部细节以格4为准」。

**含头变体启用纪律**：仅在用户明确点名（「要含头的」「头发/头饰每个角度都要看到」）时使用。角色头部承载特征（兽耳、犄角、头饰、耳部标志特征）**不构成自动升级理由**——格4 特写已含头部正面细节（兽耳写进格4 行即可）；侧面/背面的耳部轮廓损失是无头默认的已知取舍，尾部等身体特征不受影响。用户因含头产物意外出现而不满，优先按无头重出。

## 7. 题材-风格映射（槽位 {题材-风格映射} 取词）

总则：风格槽只作用于**人物材质与配色倾向**，不改变设定图的中性背景与均匀柔光——版式行（画幅/底色/光线）优先于风格槽，防止霓虹色、强投影污染中性底。

| 题材 | 风格槽填法 |
|---|---|
| 写实 / 都市 | 写实人像摄影质感，自然肤色，柔光棚拍 |
| 仙侠 / 玄幻 | 3D 国漫渲染，冷青加鎏金，发丝衣袂精细 |
| 古风 / 宫廷 | 工笔质感，暖烛光，朱红加黛青 |
| 漫剧 / 二次元 | 日漫赛璐璐或 3D 国漫渲染，色块明快，线条干净 |
| 科幻 / 赛博朋克 | 冷灰金属质感，青橙对冲，霓虹环境色微染 |
| 美式动画 | 皮克斯式 3D 角色，圆润造型，皮肤次表面散射 |
| Q版 | 二头身 chibi，大头小身，圆润轮廓 |

（与 shotshot-director vocab.md §7 同源，此处只保留与设定图相关的行。）
