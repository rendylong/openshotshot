# 生成后质检（QC）

图 ready 后立即核对，通过才交付。QC 是防漂移的最后一道闸：设定图带病流转，错误会被下游视频按镜头数放大。

---

## 1. 八项核对清单

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 格数与版式 | 四格 / 三栏齐全，顺序正确（正面→侧面→背面→特写） |
| 2 | 无头干净（T1/T4 默认） | 格 1-3 无任何头部/面部残留，颈部截断平整；含头变体则三格头部完整 |
| 3 | 权威格质量 | 格4（头部特写）大而清晰，五官与发型正面可辨认——它是后续特写镜的面部事实源 |
| 4 | 面部与身体一致 | 格4 的肤色、头身比例与格1 身体衔接自然，像同一个人 |
| 5 | 服装一致 | 款式、颜色、配饰逐格一致，与锁无出入 |
| 6 | 发型一致 | 格4 发型与发型 5 项锁吻合（无头版式下发型只有这一个视图） |
| 7 | 完整性与底色 | 格 1-3 身体头顶到脚不裁切（颈部截断属版式预期）、底色纯净无杂物、无强投影 |
| 8 | 干净 | 无文字、水印、logo、签名；单人，无多余头/手/倒影 |

---

## 2. 归因与修复

| 症状 | 归因 | 修复动作 |
|---|---|---|
| 格 1-3 长出了头/脸 | 模型忽略无头版式 | 第 1 次：「无头」三行前置 + 禁止项首条加强「严格无头，颈部平整截断」；第 2 次仍出现：改用 T2 紧凑三栏（正/背无侧面）重出 |
| 格4 面部与身体不匹配（肤色/比例断层） | 面部句与身体句割裂 | 肤色锁同时写进格4 句与体型句；禁止项补「格4 与身体肤色不符」 |
| 多头 / 多人 | 禁止项被平台截断或忽略 | 全局句首补「画面中只出现一个人」；MJ 检查 --no extra heads 是否生效 |
| 服装漂（配饰增删） | 锁描述太笼统 | 服装 6 项逐格复述；删掉易漂移的小配饰（眼镜、挂件最易漂） |
| 全身裁切 | 画幅与构图冲突 | 明确「身体头顶到脚完整入画，四周留白」；或改 1:1 四宫格（颈部截断不算裁切） |
| 参考图不像（T4） | 参考权重低 / 职责被风格参考抢走 | 收拢为「唯一人物参考」单句；移除风格参考图；换内生图通道重试 |
| 版式泄漏进下游视频 | 下游句式没写防复制 | 不是本图 QC 问题——按 usage.md §2 防泄漏句式改写下游 prompt |

---

## 3. 重试纪律

- 同一症状**最多修 2 次**；2 次不过 → 停止重试，输出：最大偏差说明 + 建议路径（降 T2 / 换通道 / 换底色 / 人工修图）。
- 每次修复只改**一个变量**（先约束句，再底色，再通道），方便归因。
- 被否掉的图**不得**当 T4 的参考图喂回（被拒产物不作父本，与 shotshot 续接纪律同源）。

---

## 4. 裁决与报告格式

| 裁决 | 含义 |
|---|---|
| ✅ 锁定 | 8 项全过，资产可进下游 |
| ⚠️ 带偏差接受 | 1 项轻微偏差（如配饰微差），已向用户说明且用户接受 |
| ❌ 需人工 | 2 次重试未过，或用户不接受偏差 |

QC 报告一行一条列 8 项结果，不整屏贴图：

```text
QC：①格序✓ ②无头✓ ③权威格✓ ④面部衔接✓ ⑤服装✓ ⑥发型✓ ⑦完整底色✓ ⑧干净✓ → ✅ 锁定
```

---

## 5. 无视觉能力时的降级

agent 无法看图时，把八项清单合并为 4 个用户可感知问题，一句话请用户核对：

> 图已生成。请快速核对 4 点：① 前三格是不是都没有头、颈部截断干净；② 特写格的五官是否清晰、和身体像同一个人；③ 四格服装是否一致、身体有没有被裁切；④ 画面里有没有文字水印或多余的手。都正常回「通过」，有问题指出第几点。

（格序与权威格质量由 prompt 骨架保证，不增加用户核对负担。）
