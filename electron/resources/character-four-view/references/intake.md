# 角色信息采集（Intake）

**原则**：出图便宜、可迭代，但「答错了版式与风格就要全部重出」的信息先问清；纯专业执行层（格序、底色、措辞、约束写法）自己定，不推回给用户。与 shotshot-director requirement-intake.md 同一纪律：一轮问完（≤4 问）、选择题优先、第一项放推荐、「你定」走缺省表并汇报。

---

## 1. 三类信息

| 类别 | 内容 | 处理 |
|---|---|---|
| **必问** | 题材画风、用途、参考图有无 | 选择题一轮问完 |
| **可默认** | 画幅、底色、站姿、头部（无头/含头）、表情 | 缺省表 + 汇报 |
| **禁问** | 格序、视角角度、背景色号、约束措辞 | 专业执行层，自己定 |

---

## 2. 快速档必问 4 项（一轮问完）

| # | 问题 | 选项示例 |
|---|---|---|
| 1 | 角色概念？（开放题，一句话即可） | 例：「35 岁女法医」「赛博朋克街头少年」 |
| 2 | 题材画风？ | 写实人像（推荐）/ 日漫二次元 / 3D 美式 / 国风仙侠 / 赛博朋克 / Q版 |
| 3 | 用途？ | 视频参考 sheet（推荐，出 T1）/ 3D 建模三视图（T3）/ 照片转人设（T4）/ 画师参考 |
| 4 | 有参考图吗？ | 无，纯文字（推荐）/ 有人物照片 / 有旧设定图 / 有风格参考 |

模式 B（有参考图）时：第 3 问固定 T4 路线，第 2 问改问「跟随参考图风格，还是重新定义画风」。

## 4. 精细档：16 项锁 + 发型 5 项 + 三色色板

触发：主角、进短剧管线、用户要求逐项锁定。逐项给出或确认；**每项必须落到物理事实，禁空词**（「成熟」「帅气」不合格——anti-slop 原则：形容词→物理事实）。

### 面部 10（含示例填法）

| 锁 | 填法示例 |
|---|---|
| 脸型骨相 | 鹅蛋脸，颧骨平缓，上庭比例标准 |
| 眉形 | 剑眉，眉峰在眉中外三分之一交界 |
| 眼型眼窝 | 细长丹凤眼，眼窝略深，窄双眼皮 |
| 瞳色 | 深褐，瞳孔反光点偏上 |
| 鼻梁山根 | 山根明显，鼻头圆润，鼻翼窄 |
| 唇形唇色 | 唇峰分明，中等厚度，豆沙色 |
| 下颌线 | 折角清晰，无赘感 |
| 耳廓 | 贴脑，耳垂小（有特写镜才需要写） |
| 标志性特征 | 左眼尾下 2mm 泪痣（**必须有且仅 1 个**） |
| 肤色肤质 | 冷白皮，鼻翼有细小毛孔，无磨皮感 |

### 服装 6 + 鞋履

面料（重磅纯棉）/ 纹理（斜纹）/ 垂坠或硬挺（硬挺）/ 做旧或崭新（微做旧）/ 金属件光泽（哑光枪灰按扣）/ 缝纫工艺（双针明线）。鞋履一句带过（黑色切尔西靴，皮面微旧）。

### 发型 5

长度剪裁（锁骨发，层次到下颌）/ 发色（黑茶色，无挑染）/ 直卷（自然直，发尾内扣）/ 刘海（轻薄法式刘海）/ 发饰（无）。

### 三色色板 + 体型

- 色板：Primary 墨绿 / Secondary 米白 / Accent 黄铜（HEX 或描述性色名）——全图色彩可数，主色出现面积最大。
- 体型：身高 + 肩腰关系 + 比例特点（165cm，肩窄腰细，腿长）。

## 5. 一句话扩锁规则（快速档默认执行）

用户只给概念时，agent 负责把概念扩成完整锁，**扩锁结果随 prompt 一起展示**（「我补全了以下设定，可改」），不逐项追问。原则：

- 从概念硬推导：职业 / 时代 / 题材决定服装与气质（女法医→工装白大褂 + 低马尾，低装饰）。
- 标志性特征必须有且仅 1 个（泪痣 / 疤 / 耳钉）——它是后续镜头与画师的记忆点。
- 颜色落到三色色板，不超色。
- 与题材-风格映射表（templates.md §7）一致，不混风格词。
- 锁一旦确定即入档：后续重出、降级 T2、多服装变体都复用同一份锁，不改写。
- 头部形态默认无头：角色头部承载特征（兽耳/角/头饰/耳部标志特征）写进格4 特写行解决，**不得**以此为由自行换含头变体；含头仅用户点名时用。
