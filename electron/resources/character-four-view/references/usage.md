# 下游使用：设定图怎么喂给模型

设定图的价值在下游兑现。交付图时按用户用途给对应句式；**下游是 Seedance 2.0 时务必先看 §3 反模式**。

---

## 1. 先分诊

| 下游 | 走 |

| Seedance 2.5 / 即梦视频 | §2 |
| Seedance 2.0 | §3（官方反模式，必读） |

## 2. Seedance 2.5 / 即梦视频（官方支持多视图主体参考）

**多图句式**——四视图拆成单图上传时用（源自 cn 附录 B #215 一致性句式，主体换成角色）：

```text
@图片1 定义同一角色的正面外观。@图片2 定义同一角色的右侧结构。@图片3 定义同一角色的背面外观。@图片4 定义同一角色的面部五官。四张图片共同定义同一个角色，成片中始终只有这一名角色。
```

**单图句式**——整张 sheet 传一张时用，**必须带版式防泄漏**（源自 en#2511）：

```text
@图片1 是该角色的设定图（character sheet），作为该人物长相、发型与服装的唯一参考。它不是起始画面：不要把设定图的灰色背景、并排站姿、棚拍灯光和分格版式带进视频。视频是实拍的场景，人物外观与@图片1 完全一致。
```

要点：设定图只拥有「人物身份与服装」维度，**不拥有**构图、灯光、背景——引用时明确声明，防止下游出灰底站桩画面。

---

## 3. Seedance 2.0（反模式：不要用多视图当参考）

官方 FAQ 结论：**不要用多视图/三视图（含 character sheet）作为 2.0 的主体参考——会加剧 ID 漂移与双胞胎问题。**（官方推荐：多视图主体参考是 2.5 才支持的能力。）

**替代方案**（官方双图句式）：

```text
{角色名} 的面部特征参考图片1（大头照），妆造参考图片2（全身照）。
```

操作：把四视图拆用——格4（头部特写）裁出当图片1（大头照、无表情最佳），格1（无头正面全身）裁出当图片2 作妆造参考；重要素材前置。如下游必须要含头全身照，用含头变体重出一张或从原参考图取。

配套防双胞胎（官方 FAQ）：人物名后标注参考图「张三（对应图片 1）」；提示词结尾加全局约束「全片只有张三一人」；单人独立照片做参考。

## 4. shotshot 短剧管线对接

- 本 skill 出的 T1 图 = shotshot 角色实体的 **sheet 槽**；**portrait 槽**（胸上近景肖像）另出，模板见 shotshot asset-first.md §3.2。
- 分工（每维度唯一 owner）：**portrait 拥有面部身份**（特写/近景镜主锚，面部像素密度高一个量级）；**sheet 拥有体型服装**（全景/中景主锚，正侧背轮廓）。
- 分镜提示词引用时声明用途：「@图片1 为该角色面部参考，@图片2 为服装体型参考」——避免两个参考抢同一维度。
- 画布项目内优先用 `canvas_script_asset` 直接生成并回写 sheet 槽（imagePrompt 填 T1 全文），不走手工导出导入；本 skill 服务于画布之外的独立出图。

---

## 5. 3D 建模 / 画师

- **3D**：T3（正 / 侧 / 3⁄4）直接可用；绑定前补 T-pose 变体（templates.md §6）；建模需要背面时，把 3/4 view 行换成 back view 出双面 turnaround。
- **画师**：图 + 16 项锁文本一起交付——锁是文字事实源，画师改稿时以锁为准，不凭记忆重画。
- 表情差分、动作集、服装变体集不在本 skill 范围（portrait 与分镜资产的事）；用户要时提示这是下一步，不要在本 skill 里硬做。
