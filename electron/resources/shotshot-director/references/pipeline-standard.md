# 中档 STD：单集创作流水线（Asset-First 六步）

适用：一集短剧 / 30s-3min 成片 / 有角色一致性诉求 / 用户要分镜表。核心纪律：**资产先行、无图不进分镜、分批确认**。

## P0 立项锁定

先完成需求澄清（`requirement-intake.md` §3 中档必问 6 项：故事来源/题材/单集时长/画幅/角色素材/台词语言）。澄清结果直接填入立项卡：

```text
【画幅】16:9 / 9:16 / 2.35:1        ← 全程每条提示词回填
【风格】题材 + 视觉基调（查 vocab.md 题材-风格映射）
【模型】Seedance 2.5（默认）/ 2.0 / Veo / Kling
【总时长】目标秒数 → 换算生成预算：组数 = ceil(总秒数 ÷ 12~15)
【平台】即梦 / 火山方舟 / fal —— 影响参数上限与合规约束
```

产出一张立项卡给用户确认。之后任何步骤不得改这五项，除非用户显式要求。

## P1 剧本工程

按 `script-engineering.md` 执行，最小闭环：

1. **30 字前提**：主角 + 核心欲望 + 不可抗力阻碍 + 失败的致命代价
2. **黄金 3 秒钩子**（四选一）：极端悬念 / 认知反差 / 情绪爆发 / 视觉奇观
3. **三幕结构**：铺垫 30% → 核心冲突 50% → 转折卡点 20%；结尾停在决策关头/身份暴露/攻击命中前一帧
4. **节拍表**：每场一句「场景目标 → 遭遇阻碍 → 升级行动 → 意外转折 → 不可逆新局面」；删掉不影响后续的场戏直接删
5. **实体提取**：从节拍表圈出跨 ≥2 镜的角色/场景/道具 → 进 P2

**大纲门禁（`requirement-intake.md` §6）**：把「前提 + 钩子 + 节拍表 + 角色/场景清单 + 卡点」组成单集大纲交用户确认（不是整页剧本）。**用户明确确认后才调 `canvas_generate_script` 创建脚本节点**（instruction = 确认后的大纲全文 + 节拍表），然后进 P2。未确认前不得建节点、不得出资产图。

## P2 数字资产包（本档核心）

按 `asset-first.md` 执行：

1. **资产清单**：每个实体一行——名称（全局唯一锚点）/ 分组 / 定位 / 一句定义 / 一致性关键词
2. **门禁 ①**：清单交用户确认「无遗漏、无多余」
3. **批量创建**：逐个调 `canvas_script_asset`（先主角后配角，先场景后道具）；每个资产自动经画布生图节点出参考图
4. **角色出图要点**：sheet 槽按固定四视图模板出（无头正/侧/背全身 + 头部特写权威格，`asset-first.md` §3.1）；portrait 槽按固定肖像模板出（`asset-first.md` §3.2，面部身份锚）。模板骨架不可改，只填槽位
5. **门禁 ②**：等参考图 ready（`generation_get_status` 批量查），用户点头才进 P3；未 ready 的资产绝不允许被分镜引用

## P3 专业分镜

按 `shot-language.md` 设计，写入脚本节点：

- 每镜五要素：`景别 · 角度 · 运镜 · 时长 · 氛围` → 对应填 ScriptShot 的 shotSize / angle / movement / duration / mood
- 动作描述进 description：**单一物理动作 + 可见完成终点**；同一镜内的构图要求（三分法/对称/景深）、转场（下一镜硬切/叠化）、接续状态（末帧关键元素）一并写进 description 文本
- entityRefs 填资产名称数组；台词进 dialogue 并**核算语速**（3.5-5 字/秒，超 24 字拆镜）；音效进 sfx（具体名词，禁「震撼音效」）
- 轴线纪律：同场戏机位保持同侧；中/全景禁 90° 侧面正拍（30°-60° 斜角建纵深）
- 景别阶梯：禁相同景别+机位连排；相邻镜头景别至少跳一级
- **门禁 ③**：分镜表整体给用户过目（表格形式：镜号/景别/运镜/时长/动作摘要/引用资产），确认后调 `canvas_script_replace_shots` 写入

## P4 提示词编译

合成界面拼出的 finalPrompt 就是最终出货（composeFinalPrompt 拼接，Agent 不重写）——**质量在写分镜时保证，主路径是唯一必经路径**。职责分两层（详见 `prompt-compiler.md` §8）：

**4a 主路径 · 写对原料（默认，必做）**——让拼接结果天然达到出货标准：

- description 按官方公式组织（主体+场景+动作+构图+转场+接续状态），运镜不在正文复述（头部参数行已有）
- sfx 字段直接写官方符号 `<具体音效>（无音乐）`；dialogue 带角色与情绪
- globalStyle 写风格总纲 + 通用禁止项；镜级禁项写 description 末尾
- 资产名内联出现在 description 语义位置（`shotshot-tools.md` §2.5）

**4b 增强路径 · 「优化提示词」（用户可选）**——用户在 Studio 第 3 步点「**优化提示词**」按钮（可选的二次打磨，自动派发指令），或对话中明确要求按目标模型精修（2.0/2.5 语法差异、时间戳分段、Veo/Kling 适配、引用编号对齐）时：读取全部分镜 → 按 `prompt-compiler.md` §9 出货规范逐镜打磨 → 调 `canvas_script_compile_prompts` 一次性回写（只动 finalPrompt，composed 重置为草稿），并告知：重新点「↻ 重新合成」或编辑字段会还原/失效。

通用纪律：台词人声永远与画面解耦（画面提示词不写对口型，台词走单独声音生成）；Seedance 2.5 单镜 >15s 拆时间戳分段，>30s 拆多镜。

## P5 质检与展开

1. 按统一自检（P0 致命/P1 结构/P2 审美）过一遍全部分镜，见 `qc-gates.md`
2. 提示用户「完成脚本编辑」→ 展开成视频生成节点 → 编组批量生成
3. 生成结果回来后按 take 四裁决处理（`qc-gates.md`）；中档只做单轮，整批废才考虑升重档流程

## 中档工具调用序列（速查）

```text
canvas_generate_script(instruction=确认后的剧本大纲全文, shotCount, globalStyle)
    ↑ 前置门禁：单集大纲已经用户明确确认，未确认不得调用
canvas_script_asset × N（角色→场景→道具 分批，等 ready）
canvas_script_replace_shots(shots=[...全字段+entityRefs名称])
  ↓ 用户在 Script Studio 三步确认
用户「完成脚本编辑」→ 展开视频节点 → 编组批量生成
generation_get_status（批量轮询，图片30s/视频60s 间隔）
```
