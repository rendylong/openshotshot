# 资产先行：Asset-First 一致性体系

中/重档 P2 阶段使用。核心信念：**跨镜一致性问题的唯一根治方案是参考图锁定**——「名字 + 外貌描述」只是索引标签，不是资产。文字描述在跨镜时会漂移，参考图不会。

## 1. 实体判定与分组

```text
character 角色：任何跨 ≥2 镜出现的具名人物
scene    场景：任何跨 ≥2 镜使用的空间
item     道具：跨 ≥2 镜出现的关键物品（一镜性物品不入清单）
```

对应 `canvas_script_asset` 的 group 参数。判定标准只有一条：**复用次数 ≥2**。只在 1 镜出现的群众/陈设直接写进 description。

## 2. 资产清单（门禁 ① 的交付物）

每个实体一行，给用户确认：

```text
[CHR] 林晚｜主角｜25岁女，外卖员，短发微卷，米色风衣｜锚点关键词：碎发、 tired 眼神
[CHR] 陈默｜男二｜30岁男，咖啡馆老板，金丝眼镜｜锚点：镜片反光、围裙
[SCN] 老街咖啡馆｜主场景｜雨夜暖黄，木桌暖灯，临街玻璃门
[PRP] 碎屏手机｜关键道具｜屏幕裂纹贯穿转账记录，关键情节点
```

规则：名称全局唯一（将作为 entityRefs 锚点，画布按名称解析成内联引用）；一句话定义给用户看，一致性关键词供出图和后续镜描述复用。

## 3. 角色资产：16 项锁 + 固定双模板（sheet 四视图 + portrait）

角色固定出两张参考图，对应 ShotShot 实体的默认两槽 `[sheet, portrait]`。**模板骨架固定不可改，只允许填 {花括号} 槽位**（槽位内容从 16 项锁与题材-风格映射取）——固定骨架保证同一项目里所有角色的设定图版式一致、可横向比对。

### 3.1 Character Sheet 固定模板（四视图，sheet 槽，由 `canvas_script_asset` 自动生成）

```text
角色设定图（character sheet），同一人物同一服装同一光线，四格横向并排：
格1——无头全身正面站姿（颈部平整截断，展示全身比例与剪裁）
格2——无头全身侧面站姿（右侧 90°，颈部平整截断，展示侧面轮廓与剪裁）
格3——无头全身背面站姿（颈部平整截断，展示服装背面与背部剪裁）
格4——头部五官正面特写（大比例，神情沉静，含发型正面，面部细节权威）
画幅 16:9，纯浅灰无缝背景，均匀柔光无强投影，全身完整不裁切，四格比例一致。
体型：{身高体型}。服装：{6 项锁 + 鞋履}，全身完整展示剪裁。
面部（格4 为唯一事实源）：{五官 10 项锁}，{标志性特征}。发型：{发型 5 项}。
风格：{题材-风格映射}，细节锐利。
禁止：格1-3 出现头部或面部、多个头、格4 与身体肤色不符、四格间服装差异、动态姿势、文字水印。
```

要点：**无头默认（2026-09-12 实测修订）**——小图里的脸是漂移源且像素浪费，格 1-3 只保留身体事实，面部唯一事实源收拢到格 4；防漂移靠「无头身体 + 格 4 权威 + 禁止项」三重约束。格 1-3 颈部截断是版式预期，质检不视为裁切；侧面/背面的发型展示由格 4 + 发型锁承担。确需各视角发型·头饰展示时，格 1-3 换回含头行（格1 全身正面站姿·含头 / 格2 侧面 90°·含头侧脸清晰 / 格3 背面·含头展示发型背面）并把禁止项首条改回「四格间面部/发型/服装差异」。（与 `character-four-view` skill 的 T1 默认版式一致。）

### 3.2 Portrait 固定模板（portrait 槽，特写镜的身份锚）

```text
角色肖像（portrait），胸部以上近景，肩部微侧 15°、面部正对镜头，眼神平视镜头，中性自然表情。
纯浅灰背景，柔和伦勃朗光（左前 45° 单侧柔光），肤色质感、发丝、瞳孔细节清晰。
五官：{五官 10 项锁}。发型：{发型 5 项}。标志性特征：{痣/疤/泪痣等}。
服装露出领口：{主服装领口，与设定图一致}。
风格：{题材-风格映射}，与该角色 character sheet 完全一致。
禁止：夸张表情、笑容、多人、手部入画、文字水印。
```

要点：**中性表情 + 平视镜头**——portrait 锚定的是「这个人长什么样」，不是情绪；表情留给每个镜头的表演。领口入画保证与 sheet 服装可互相对照。

**portrait 在生视频时的作用**：脚本节点展开生成时（planShotExpansion），角色所有 ready 槽会自动挂载为该镜头视频生成节点的参考图——portrait 与 sheet 一起进模型。分工遵循「每维度唯一 owner」：**portrait 拥有面部身份**（五官/肤色/发丝），特写与近景镜的主要身份锚——胸上近景的面部像素密度比 sheet 里的小脸格高一个量级；**sheet 拥有体型服装**（比例/剪影/正侧背轮廓），服务全景与中景。分镜提示词引用时必须声明用途（如「@图片1 为该角色面部参考，@图片2 为服装体型参考」），避免两个参考抢同一维度。

### 3.3 出图分工

- **sheet 槽**：`canvas_script_asset` 调用时自动经画布生图节点生成，imagePrompt 填 §3.1 模板全文。
- **portrait 槽**：工具只出 sheet，portrait 在 Script Studio 第 2 步资产抽屉里对 portrait 槽点「生成」（imagePrompt 填 §3.2 模板全文），或由 agent 另建图片生成节点并回写该槽。
- 两张图都 ready 才算该角色资产锁定（sheet 用于全身/服装锚定，portrait 用于特写镜锚定）。

### 16 项一致性锁（写进 consistency 字段，每镜描述涉及该角色时从锁里取词）

```text
面部 10：脸型骨相 / 眉形 / 眼型眼窝 / 瞳色 / 鼻梁山根 / 唇形唇色 /
        下颌线 / 耳廓（如有特写）/ 标志性特征（痣/疤/泪痣）/ 肤色肤质
服装 6：面料 / 纹理 / 垂坠或硬挺 / 做旧或崭新 / 金属件光泽 / 缝纫工艺
+ 三色色板：Primary / Secondary / Accent（HEX 或描述性色名）
```

规则：A/B 级角色（主角/重要配角）强制出四视图 sheet + portrait；C 级群众演员可文字降级。未声明的特征不得在后续镜中出现——**角色改名换装 = 新资产**（`CHR-林晚-雨衣` 与 `CHR-林晚-家居` 是两个资产）。

### 亲缘推导（家族角色）

T1 男女主先锁脸模 → T2 亲属继承 T1 的 40%-60% 骨相特征 + 共享色板 ≥1 色 + 年龄化差异 → **直接出图**（不是文字推导）→ T3 群像按需。

## 4. 场景资产

### 分型出图

- **文戏场景**：机位调度视角（展示空间关系 + 固定参照物 + 光源方向），如「咖啡馆全景，临街玻璃门在右，吧台在左深处，暖黄吊灯 3 盏」。
- **动作场景**：站位图视角（地形 + 中央对决区 + 双方依托位 + 纵深边界），供分镜对应机位。

### 空间快照（写进 consistency）

```text
布局：门（右）/ 吧台（左深）/ 窗（正面）
光源：暖黄吊灯 ×3（顶）+ 临街霓虹（右窗，蓝红交替）
时辰：夜 · 雨
```

- 时段/天气/季节是场景资产的一部分：`SCN-咖啡馆-夜雨` 和 `SCN-咖啡馆-晨` 是两个变体资产，或一个资产在 consistency 里写清光照逻辑。
- 同场景所有镜头必须引用同一资产，保证窗在右边永远在右边。

## 5. 道具资产

- 关键道具（承载剧情）必须出图：`PRP-碎屏手机`。
- imagePrompt 强调防穿模细节：尺寸比例（「手机长度 ≈ 手掌 2/3」）、材质、与手部的握持关系。
- 状态变体单列：`PRP-信封-封口` vs `PRP-信封-拆开`。

## 6. 工具对接（参数契约详见 shotshot-tools.md）

```text
canvas_script_asset(
  scriptNodeId, group="character",
  name="林晚",                      ← 全局唯一锚点
  role="主角，25岁外卖员",
  appearance="短发微卷，米色风衣，tired 眼神",
  consistency="圆脸骨相+下垂眉+内双+右眼角泪痣；风衣：华夫格面料，微垂坠；
               色板：Primary 米白 / Secondary 焦糖 / Accent 雾蓝",
  imagePrompt="四视图 sheet 模板全文（§3.1，槽位已填）"
)
```

- 参考图自动经画布生图节点生成并回写到实体槽位。
- 轮询节奏：图片 30s 间隔批量查 `generation_get_status`；一个没出不要急着重发。
- 出图不满意 → 在 Script Studio 第 2 步的资产卡上「重新生成」，或调整 imagePrompt 后重调工具。**不要在参考图 ready 前写分镜**。

## 7. 分批确认节奏

```text
第一批：T1 主角（1-2 个）→ 出图 → 用户确认
第二批：T2/T3 配角 → 确认
第三批：场景 → 确认
第四批：道具 → 确认
全部锁定 → 门禁 ② 通过 → 进 P3 分镜
```

一次性把 10 个资产全部丢给用户确认 = 没有确认。分批的意义在于：前面批次的问题（画风跑偏、锁不全）不会扩散到后面。

## 8. 资产自检（门禁 ② 通过条件）

- [ ] 清单经用户确认，无遗漏无多余
- [ ] 所有 A/B 级角色已出四视图 sheet + portrait 两张参考图且用户点头
- [ ] 每个 scene 有空间快照 + 光源逻辑
- [ ] 关键道具有防穿模细节
- [ ] 所有资产参考图 state=ready
- [ ] 名称无重复（锚点唯一性）
