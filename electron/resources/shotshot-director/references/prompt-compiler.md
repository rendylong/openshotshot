# 提示词编译：从分镜到模型就绪 finalPrompt

把分镜表（结构化数据）编译成单条自然语言提示词。心智模型是**编译器**：输入 ScriptShot + ScriptEntity + globalStyle，输出一条该模型最优的 prompt。内部结构化、出货自然语言。

## 1. Seedance 官方进阶公式（2.0/2.5 通用）

```text
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

特殊符号（音频类内容）：

| 符号 | 用途 | 例 |
|---|---|---|
| `（ ）` | 音乐/BGM | `（压抑的合成器低音渐强）` |
| `< >` | 音效 | `<雨声持续，玻璃碎裂声>` |
| `{ }` | 台词 | `{「你终于来了。」，女声，疲惫沙哑}` |
| `【 】` | 字幕/标题 | `【第一集】` |

## 2. 版本差异适配

| 维度 | Seedance 2.0 | Seedance 2.5 |
|---|---|---|
| 单段时长 | 4-15s | 4-30s |
| 分段语法 | 镜头序号 `镜头1：… 镜头2：…` | **整数秒时间戳** `0-3秒：… 4-7秒：…` |
| 参考素材 | ≤3 视频 + 9 图 + 3 音频 | ≤30 图 + 10 视频 + 10 音频（合计 50） |
| 主体参考 | 单视图 | 多视图主体参考 |
| 画幅 | 固定档位 | 任意比例 [0.4, 2.5] |
| 输出 | — | MOV 保证声画同步 |

## 3. 编译序（每镜按此顺序组装）

```text
① 技术参数头：[画幅比] [时长 Xs] [风格总纲]
② 主体（从实体锁取词）：精准外观描述，@引用写明用途
③ 场景环境：空间 + 光源 + 时辰（从场景资产 consistency 取）
④ 动作：单一物理动作 + 可见终点；多动作按时间戳/镜头序号分段
⑤ 运镜：一个主运镜 + 相位（含从上镜继承的运动向量）
⑥ 声音：BGM（）/ 音效<> / 台词{} 分行写清
⑦ 风格画质：2-3 个风格词 + 质感词
⑧ 负面排除：分层负面（见 §6）+ 保留节拍排除（Do not yet…）
```

压缩优先级（超长时按此删）：先删泛风格词、重复形容词、参考图里已可见的背景描述；**绝不动**引用说明 > 开场状态 > 动作+终点 > 声音设计 > 连贯性锚点。

## 4. 引用语法（@ 体系）

```text
@图片1-9 / @视频1-3 / @音频1-3（Seedance 2.5 可到 @图片30）
```

**铁律：每个引用必须显式说明用途。** 13 种用途：首帧 / 尾帧 / 角色外观 / 场景背景 / 运镜复刻 / 动作复刻 / 视觉特效 / 节奏速度 / 音色 / BGM / 音效 / 服装 / 产品外观。

组合示例：

```text
以@图片1的角色形象为主角，@图片2的场景为背景，
动作：她推开玻璃门走入雨中，回头望向店内。
参考@视频1的运镜节奏：缓慢推镜后随人物右移。
<雨声、门铃叮咚>（慵懒的爵士钢琴）
```

编号分配规则（多镜项目）：公共素材固定编号（角色 @图片1、场景 @图片2），每镜独立素材（首帧/道具特写）在公共编号后递增。

## 5. 时长与分段

```text
4-7s   ：不分段，1-2 个核心画面
8-15s  ：时间分段 2-3 段（2.5）或镜头序号 2-3 镜（2.0）
16-30s ：仅 2.5；时间戳 3-4 段，段间必须有承接（上一段末状态 = 下一段首描述）
>30s / >15s(2.0)：拆成多镜，走画布多节点；跨镜衔接 = 接续状态字段
```

超长分段拼接（多镜串成长片）：

```text
段1 正常生成
段2+ 「将@视频1延长 X 秒，新增内容：…」
衔接点：上一段结尾状态必须 = 下一段开始状态（写进两段提示词）
>60s：拆独立场景分别生成，剪辑软件拼接
```

## 6. 负面排除（分三层，写进提示词末尾或约束段）

```text
画面防崩：禁止画面文字、水印、logo、多余手指、肢体畸形、面部扭曲
题材专项：按题材加（古装：禁止现代物品 / 现代：禁止古装元素 / 美食：禁止生熟混淆）
镜头动态：禁止镜头快切（要一镜到底时）、禁止慢动作、禁止镜头反向
叙事排除：已完成节拍不复现 + 保留节拍提前演（Do not yet show…）
```

## 7. 多模型适配（ShotShot 模型目录路由）

| 模型 | 适配要点 |
|---|---|
| Seedance 2.5 | 主力：时间戳 + @多参考 + 符号系统（本文档默认） |
| Seedance 2.0 | 镜头序号替代时间戳；参考上限收紧；单段 ≤15s |
| Veo 3.1 | 英文优先；原生音频（对白直接写 dialogue:）；首尾帧模式用 first-last-frame；避免中文符号系统，声音用 audio: 描述 |
| Kling 3.0 | 运镜指令友好（camera movement 单列）；负向提示词有独立字段则从正文剥离 |
| Hailuo / Wan / LTX | 按目标平台参数表回退到通用 8 字段公式 |

不确定目标模型的参数时：明示「建议在生成节点确认该模型参数」，不凭记忆编造上限。

## 8. 与 ShotShot composeFinalPrompt 的关系（两层分工）

**合成界面右侧拼好的 finalPrompt 就是最终生成用的提示词（拼好即出货）——所以质量必须在写分镜时保证，而不是靠事后改写。** finalPrompt 由脚本节点确定性拼接（composeFinalPrompt），Agent 从不「重新生成」它；「优化提示词」按钮只是用户可选的二次打磨。Agent 的职责分两层：

### 主路径：写对原料（默认，Agent 不碰 finalPrompt）

模板各字段的可控性：

| 模板输出 | 来源 | Agent 可控 |
|---|---|---|
| 【景别 · 角度 · 运镜 · 时长s · 氛围：xxx】 | shot 字段（模板硬编码格式） | 填字段值，格式不可控 |
| {description} | description | **完全可控** |
| 音效：{sfx} | sfx（前缀硬编码） | 内容可控 |
| 台词：「{dialogue}」 | dialogue（「」包裹硬编码） | 内容可控 |
| — 实体绑定 — [角色/场景/道具] | entityRefs（块硬编码） | 不可控 |
| — 全局风格 — {globalStyle} | globalStyle（块头硬编码） | 内容可控 |

主路径 = 把可控原料写到最优，用户点「合成」拼出的 finalPrompt 天然接近可投喂状态：

- description 按官方公式组织（主体+场景+动作+构图+转场+接续），**运镜不在正文复述**（头部参数行已有）
- sfx 内容直接写官方符号：`<具体音效>（无音乐）`；dialogue 带角色与情绪
- globalStyle = 风格总纲 + 通用禁止项；镜级禁项写 description 末尾
- 资产名内联在 description 语义位置（shotshot-tools.md §2.5）

### 增强路径：模型定制编译（可选的「优化提示词」，非默认路径）

需要按目标模型精修（2.0/2.5 语法差异、时间戳分段、Veo/Kling 适配、引用编号对齐生成节点挂载顺序）时，agent 才回写 finalPrompt。入口有两个：**用户在 Studio 第 3 步点「优化提示词」按钮**（可选操作，自动派发优化指令，用 `canvas_script_compile_prompts` 批量回写），或对话中明确要求。两条纪律：

1. **覆盖风险必须告知**：用户之后在 Studio 点「↻ 重新合成」会用默认模板覆盖精修稿；回写前说明，回写后在交付说明里注明「finalPrompt 为模型定制稿，重新合成会还原」。
2. 任何字段再被编辑都会使 composed 失效——agent 回写时机放在用户确认分镜字段之后，避免白写。

## 9. finalPrompt 出货规范（增强路径：模型定制编译时适用）

Script Studio「合成」按钮产出的是**模型无关的中间格式**，直接投喂不一定是最佳实践。本节是**增强路径**的规范：用户要求按目标模型精修、agent 决定回写 finalPrompt 时按此转换（主路径只需遵守原料规则，见 §8）。

8 条规则分两类：

- **原料规则（规则 2/3/4/6/7/8）**：写 shot 字段时就遵守，主路径下拼接结果自动达标——不需要回写 finalPrompt。
- **结构规则（规则 1/5）**：涉及模板固有结构（【】元信息行、展示块），原料无法解决。三个出路：① 接受默认结构（火山社区实践中【】块投喂亦有效，但与官方字幕符号有冲突风险）；② 增强路径回写 finalPrompt；③ 产品侧改进 composeFinalPrompt 模板（【】改半角 [、展示块可配置）。

逐条规则：

1. **元信息行半角化**：头部 `【景别 · 角度 · 运镜 · 时长 · 氛围】` 块转为 `[画幅 · 时长 · 景别 · 主运镜]` 半角参数行。官方符号体系里**全角【】保留给真正要显示的字幕**——元信息顶着【】有被渲染成字幕卡的风险。
2. **运镜全文唯一**：参数行里的运镜是全文唯一运镜指令，正文禁止复述。「缓慢下推」「dolly in」「slow push in」三重出现且互不相同 = 已知的冲突废片模式。接续向量写成相位（「承接上镜右移动量，缓缓落窗」）。
3. **单一语言到底**：中文提示词不夹英文镜头术语（slow push in / dolly in 这类与中文运镜重复时删英文）；要英文输出就整条英文。
4. **声音用官方符号**：`<音效>`、`（音乐）`、`{台词}`。「无音乐」写成 `（无音乐）` 并进禁止项，不要用散文表述。
5. **删展示块**：「— 实体绑定 —」「— 全局风格 —」是 Studio 界面信息；出货时实体以文内名称 + 参考图 @引用 承载，全局风格并入正文风格行。
6. **全局风格与单镜氛围**：允许张力（系列是治愈系、本镜压抑是先抑后扬的有意设计时保留），但**无设计意图的语义对撞要统一**，同一行内不得出现互斥词直接并置。
7. **结尾约束段必备**（官方公式第八项）：至少「禁止：画面文字、水印」+ 本镜动态禁项。
8. **句尾无悬空资产名**（联动 shotshot-tools.md §2.5 内联规范）。

## 10. anti-slop 自检（出货前最后一遍）

删掉/替换这些：高清、超清、高品质、震撼、大片质感、极致、唯美、史诗感、电影级（空用）、充满张力。
换成物理事实：光源位置与颜色、材质反光方式、镜头焦段感、具体动作、具体声音名词。
「极具压迫感」✗ → 「低机位仰拍，人物剪影占画面 2/3，顶光只留出面部轮廓」✓

## 12. 分镜图编译（storyboard-first 模式）

分镜图先行模式下每镜**双提示词、各司其职**：storyboardPrompt 编译「静态关键帧」（出图，产物作为该镜视频首帧）；finalPrompt 编译「运动指令」（I2V 出视频，以分镜图为首帧前提）。两者写的是不同的东西，编译规则分开执行。

### storyboardPrompt：静态画面转译四则

1. **动作取「进行中瞬间」单帧**：抓可见动作的标志性时刻（跃起中、翻页中、半回头），不是完成态——完成态留给视频去演。
2. **去运镜、时长、声音**：静态图没有这些维度。时长参数、运镜指令、音效/台词/音乐符号一概不写。
3. **保留构图、光线、氛围、实体**：构图/光源/氛围词照常写（同 §3）；实体身份锚来自挂载的资产参考图，@ 用途声明不变（「@图片1 的角色外观」）。
4. **帧间衔接**：上一镜完成态 ≈ 本镜起点；本镜分镜图 = 本镜 finalPrompt 运动的起点画面。写分镜图时想清楚「运动的起帧是什么」。

参考图按镜按需选择，不为凑数全挂：特写 → portrait、全身 → sheet、空间 → 场景图；@ 用途声明不变。

### finalPrompt：I2V 形态（以首帧为前提只写运动）

分镜图已把画面钉死在像素里，文字只负责「让这一帧动起来」：

```text
[画幅 · 时长 Xs · 景别 · 主运镜]
从首帧开始，+ 单一运动（含可见终点）
<音效>（BGM）{台词}
禁止：…
```

- 开头点明首帧前提（「从首帧开始，她推开玻璃门」），后接**单一运动** + 镜头运动 + 声音（符号系统同 §1/§9）。
- **绝不复述画面**：场景、构图、光线、外观已由首帧承载，再写一遍就是冗余；更要命的是文字与像素矛盾时，**文字成为漂移指令**——模型按文字重画画面，身份锚崩、首帧白挂。分镜图画错了就重出分镜图（修像素），不要用文字跟画面讲道理。
