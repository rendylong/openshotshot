# 质检门禁：P0/P1/P2 + take review

生成前自检与生成后裁决。原则：**分级处理**——致命项阻断交付，结构项自动修复，审美项给建议不强拦。QC 产物只作附件存档，绝不进提示词正文。

## 1. 生成前：三级门禁

### P0 致命（命中任何一条 = 阻断，必须修复后才能写画布/提交生成）

- [ ] 单镜/单段时长超模型上限（2.0 >15s，2.5 >30s）
- [ ] 台词时长超镜头预算（语速核算未过）
- [ ] 五官/服装/道具与资产锁矛盾（跨镜漂移点在提示词里就已埋下）
- [ ] 跨轴（同场戏机位跑到轴线另一侧）
- [ ] 引用了不存在/未 ready 的资产（悬空 entityRefs）
- [ ] 混入内部标签（叙事分析、QC 卡内容出现在 description/finalPrompt）
- [ ] 用户 P0 锁定参数被改动（画幅/风格/模型/总时长）
- [ ] 写实真人脸参考素材（平台拦截，换虚构描述或风格化）

### P1 结构（自动修复后向用户汇报改了什么）

- [ ] 一镜多动作（拆镜或砍动作）
- [ ] 镜头时长全篇雷同（重排节奏密度：3-5s/2-2.5s/0.8-1.5s 分层）
- [ ] 相同景别+机位连排（按景别阶梯跳级）
- [ ] 缺反应镜头（金句后 0.3-0.8s）
- [ ] 光源无物理来源（每个光源写位置+颜色+动机）
- [ ] 运镜向量断裂（上镜右摇出、下镜突然左拉）
- [ ] 接续状态缺失（多镜项目每镜 description 末尾必须有【接续】行）

### P2 审美（给建议，用户定夺）

- [ ] 空镜无戏剧任务（每个空镜给一个信息职能：转场/隐喻/呼吸）
- [ ] 形容词空泛未转译物理事实（跑 anti-slop，见 prompt-compiler.md §10）
- [ ] 声音层次不清（对白 0dB > SFX -6dB > BGM -14~-18dB；激烈段 BGM 避让）
- [ ] 构图平庸（居中对称满天飞 → 换三分法/框架/引导线）

## 2. 生成后：take review 四裁决

每个生成结果（视频节点成片）必给一个裁决：

| 裁决 | 判定 | 动作 |
|---|---|---|
| **accept** | 完成节拍、无连贯性破坏 | 把 observed_end_state（实际看到的末帧状态）写回链条，下一镜以此为开场 |
| **accept_with_deviation** | 有偏差但不伤连贯 | 记录偏差内容；偏差成为后续镜的「既成事实」 |
| **repair** | 方向对、局部可修 | **单变量对照重roll**：一次只改一个变量（只换运镜 / 只改光线 / 只精修一个动作描述） |
| **reject** | 节拍失败 / 身份漂移 / 不可用 | **不作续接父本、不进入正典**；回 prompt-compiler 修提示词或回资产层重锚 |

review 记录（中档口头汇报，重档存档）：

```text
TAKE-U02-镜3
observed_start/end_state：门口背光人影 → 她转头，信纸离手
completed_beats：回头 / 信纸脱手
incomplete_beats：信纸落地（留镜4）
continuity_breaks：无
裁决：accept_with_deviation（发丝飘动方向与上镜风向相反，不影响识读）
```

## 3. 正典纪律（多镜/多组项目的根本法）

1. **正典** = 已 accept 镜头链 + 资产锁。冲突时正典赢。
2. **observed > planned**：绝不假装计划中的画面发生了；下一镜开场永远写实际看到的末帧。
3. **rejected 不续接**：被拒片段当续接源 = 把错误固化进链条。
4. **重锚规则**：连续以生成结果为源的续接 ≤2 代（硬顶 3），超限强制回资产参考图重开。**计划阶段就排布重锚点，不要等看见漂移才行动**——场景切换天然是重锚点。
5. **场景边界 = 有意图的剪切**：换场必回资产参考图重开，extension_depth 归零。

## 4. 资产一致性检查（生成结果 vs 资产图册）

- [ ] 脸型/五官对标角色四视图 sheet 与 portrait（特写镜逐项比对 portrait，全身镜比对 sheet）
- [ ] 服装材质/色板一致（截帧对比）
- [ ] 道具状态符合剧情进度（碎屏镜不能出现完屏）
- [ ] 场景空间关系一致（窗/门/光源方位）
- [ ] 多角色同镜无脸混淆（色彩锚定是否生效）

不一致 → P0 阻断该镜 → 修复路径：加强提示词锁描述 → 换参考图挂载方式（首帧图直接锁画面）→ 资产图重出 → 重锚。
