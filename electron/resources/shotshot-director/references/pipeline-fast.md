# 轻档 FAST：单镜头直出

适用：一个镜头 / 一条 ≤15s 片段 / 用户要一条「拿来就能生成」的提示词。目标：**40 秒内出片**，不跑门禁、不建资产（除非用户明确给了参考图）。

## 流程（五步）

### 1. 需求澄清（必问清单见 `requirement-intake.md` §3 轻档）

一轮问完 4 项（选择题，第一项放推荐）：**画幅 / 时长 / 用在哪 / 有无参考素材**。模型默认 Seedance 2.5，用户点名再切换。用户说「你定」时按缺省表取值并汇报。

### 2. 镜头大纲确认（建节点/动笔前的硬门禁）

先给用户看 ≤5 行的镜头大纲（主体 / 动作与终点 / 场景与时段 / 氛围风格 / 参数，模板见 `requirement-intake.md` §6），可附 1-2 个备选创意方向。**用户明确确认后才进入下一步**；用户显式说「不用确认」时记录授权并跳过等待。

### 3. 按 8 字段公式写提示词

```text
主体/角色设定 → 场景/环境 → 动作/运动 → 运镜 → 时间分段 → 转场/特效 → 声音设计 → 风格/情绪
```

- **主体**写具体：「一个穿米色风衣的短发女人」优于「一个女人」。
- **动作**是一个可见动作 + 可见终点：「她推开咖啡馆的门，风铃晃动，门在身后合上」——末帧（门合上）≠ 首帧（伸手推门）。
- **运镜**从词库选（`vocab.md`），一条提示词只给一个主运镜；推镜和摇镜混写是常见废片原因。
- **时间分段**（≥8s 才用）：
  - Seedance 2.5：`0-3秒：… / 4-7秒：… / 8-10秒：…`（整数秒）
  - Seedance 2.0：`镜头1：… / 镜头2：…`
  - 4-7s 不分段，聚焦 1-2 个核心画面。
- **声音**用官方符号：BGM 写 `（轻快的爵士钢琴）`、音效写 `<风铃声渐强>`、台词写 `{「你终于来了。」，女声，疲惫}`、字幕写 `【片名：归途】`。
- **风格**从 `vocab.md` 风格库选 2-3 个词，禁止堆砌泛词（「高清、高品质、震撼」属于 anti-slop）。

### 4. 自检（7 错清单，10 秒过一遍）

1. 每个引用的素材都写明用途了吗？（模糊引用 = 废片首因）
2. 运镜指令互相矛盾吗？（「缓慢推近」+「快速环绕」只能留一个）
3. 时长和内容量匹配吗？（15s 塞 5 个动作必翻车；1 秒 ≈ 1 个动作）
4. 上传的素材都被 @ 到了吗？（传了没引用 = 浪费名额还添乱）
5. 有声音设计吗？（哪怕一句「环境音：雨声」）
6. 写实真人脸素材了吗？（平台自动拦截，换成插画/3D 风格或虚构人物描述）
7. 结尾有可见终点吗？（「她转身走入人群深处」✓；「气氛越来越紧张」✗）

### 5. 写入画布 + 交付

- 用户要「可复用的」：`canvas_generate_script` 建节点 + `canvas_script_add_shot` 写入这一镜，提示用户进 Script Studio 第 3 步确认 finalPrompt。
- 用户只要文本：直接给提示词 + 参数建议（画幅/时长/建议模型），说明可直接贴进即梦或生成节点。

## 快速示例

用户：「帮我来一条雨夜霓虹街道的镜头，竖屏，赛博朋克感」

```text
【9:16 · 5s · Seedance 2.5】
一个穿透明雨衣的银发女孩站在积水 street 中央，霓虹招牌的红蓝光在她脸上流动。
雨滴砸落积水泛起涟漪，她缓缓抬头看向镜头方向，瞳孔里映出闪烁的招牌倒影。
运镜：低机位缓慢推镜，从积水倒影摇起至面部特写。
<雨声持续，远处电流嗡鸣>（压抑的合成器电子乐）
风格：赛博朋克，霓虹辉光，湿反射地面，电影感景深
```

自检：单动作（抬头）、有终点（面部特写定住）、单一运镜、声音齐、无泛词。✓
