# 词库：镜头语言 / 风格 / anti-slop / SFX

所有词表供分镜字段与提示词直接取用；ShotShot 表单下拉的建议词在 §1 标注 ★。优先用标准词（表格可读、Studio 可选中），词表没有的概念用准确的专业描述，不要生造词。

## 1. 景别（shotSize）

```text
★特写  ★近景  ★中景  ★全景  ★远景          ← Studio 建议词
大远景 / 大特写 / 中近景 / 过肩(OTS) / 微距 / 鱼眼
```

取用规则：情绪表达用近端（特写/近景），空间叙事用远端（全景/远景）；建立镜头用大远景；爆点用大特写。

## 2. 角度（angle）

```text
★平视  ★俯拍  ★仰拍  ★侧机位                ← Studio 建议词
低机位 / 高机位鸟瞰 / 荷兰角(倾斜) / POV 主观 / 顶摄 / 背影机位 / 45°斜角 / 30-60°斜角
```

取用规则：压迫感=低机位仰拍；渺小感/全知=俯拍鸟瞰；不安/失控=荷兰角（全片 ≤1 次）；沉浸=POV。

## 3. 运镜（movement）

```text
★固定  ★推镜  ★拉镜  ★摇镜  ★移镜  ★跟镜    ← Studio 建议词
环绕(弧形围绕) / 升降 / 甩镜(转场用) / 手持晃动 / 斯坦尼康平滑 / 航拍俯冲 /
希区柯克变焦(推近+后退，眩晕感) / 一镜到底 / 轨道横移
```

取用规则：一镜一主运镜；复合运镜写相位（「前 2s 缓推，后 3s 右移跟随」）；甩镜只做转场；希区柯克变焦全片 ≤1 次。

## 5. 光影与色调（写进 description / globalStyle）

```text
自然光 / 伦勃朗光 / 侧逆光 / 顶光 / 底光(恐怖) / 轮廓光 / 实用光源(画面内的灯) /
冷暖对冲 / 高调明亮 / 低调布光 / 剪影 / 黄金时刻 / 蓝调时刻 / 霓虹辉光 / 烛光暖黄
```

纪律：每个光源写**位置+颜色+动机**（「窗外冷蓝月光，动机：雨夜」）；禁「日景冷蓝光」这类无来源光。

## 8. anti-slop 禁用表（提示词出货前扫描）

**禁用**（空泛，AI 感来源）：高清、超清、高品质、震撼、大片质感、极致、唯美、史诗级、电影级（空用）、充满张力、极具压迫感、超凡脱俗。

**替换示范**：

```text
✗ 极具压迫感     → 低机位仰拍，人物剪影占画面上 2/3，唯一顶光只勾出面部轮廓
✗ 氛围很紧张     → 时钟滴答声放大，她攥紧的手在桌下微微发抖
✗ 画面精美       → 侧逆光勾勒发丝，浅景深虚化背景人群
✗ 史诗感大战     → 万人军阵从山脊线漫过，尘土在逆光中分层
```

原则：**形容词 → 物理事实**（机位、光源、材质、动作、声音名词）。

## 9. SFX 词库（音效要具体名词，禁「震撼音效」）

```text
动作：Bone Crack / Impact Thud / Sword Ring / Fist Whoosh / Body Fall
环境：Rain on Window / Distant Thunder / City Ambience / Insect Night / Wind Gust
科技：Electric Hum / UI Beep / Servo Whir / Sonic Boom / Data Stream
情绪：Heartbeat / Breath Sharp / Silence Ring(耳鸣) / Clock Tick
物件：Glass Shatter / Door Creak / Paper Rustle / Fabric Stretch / Phone Vibrate
史诗：Sub-bass Drop / Metallic Screech / Apocalyptic Detonation / Crowd Roar
```

音量层次纪律：对白 0dB > 音效 -6dB > BGM -14~-18dB；激烈段 BGM 自动避让。

## 10. 台词标注格式

```text
{「台词内容」，角色名/音色，情绪标签}
例：{「你终于来了。」，女声，疲惫沙哑}
    {「先生请留步。」，男声，谄媚中带迟疑}
```

语速核算（写台词前）：可发音字符数 ÷ 3.5-5 字/s + 标点停顿 ≤ 镜头时长；单句 >24 字拆镜。
