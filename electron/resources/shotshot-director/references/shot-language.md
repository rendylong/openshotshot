# 镜头语言：专业分镜设计

中/重档 P3 阶段使用。目标：让分镜表达到「导演专业」水准——这是 ShotShot 脚本节点当前最弱的一环，也是本 skill 的核心增值。

## 1. 镜头五要素（每镜必写）

```text
[景别] · [视角/角度] · [运镜方式] · [时长] · [氛围]
   ↓         ↓           ↓         ↓      ↓
 shotSize  angle     movement  duration  mood   ← ScriptShot 字段
```

五个字段全部从 `vocab.md` 词库取标准词（保证 Script Studio 下拉可选、表格可读），词库没有的表达用自由文本（字段接受自由输入）。

## 2. 景别阶梯与跃迁

```text
大远景 → 远景 → 全景 → 中景 → 中近景 → 近景 → 特写 → 大特写
```

- **禁相同景别 + 相同机位连排**（观众会觉得「没剪」）。
- 相邻镜头景别至少跳一级；情绪爆点用极限两极对跳（大特写 ↔ 大远景）制造奇观。
- 景别与动作幅度匹配：大动作给全景，微表情给特写；中景拍全手部动作。
- 开场建立镜头（establishing shot）用大远景/远景，一次交代空间关系。

## 3. 运镜设计

- **一镜一主运镜**：推、拉、摇、移、跟、环绕只能有一个主导；复合运镜要有明确相位（「前 2s 缓推，后 3s 随她左移」）。
- 运镜必须有动机：跟随动作、揭示信息、传递情绪，而不是为动而动。
- 同运镜连续 ≤2s、同景别连续 ≤3s（短剧完播率节奏）。
- 武戏/高潮：固定镜头 + 快切反而比乱运镜有力；Hit-Stop（命中瞬间 1-2 帧定格）比慢动作有效。
- **升格慢镜默认禁用**（实测破坏节奏）；蓄力段只用短促凝神。
- 续接镜的运镜要继承上一镜的运动向量（上镜向左摇出，下镜不要突然反向拉）。

## 4. 轴线与空间（连贯性命门）

- **180° 轴线**：同场对话/动作，所有机位保持在动作轴线同一侧；跨轴 = 人物方向无故反转，观众瞬间出戏。正反打机位在轴两侧 30°-45° 交错。
- **中/全景禁 90° 侧面正拍**（街机横版感、画面纸片化）：用 30°-60° 斜角建立纵深，前后景有参照物。
- **Eye-Trace 视线流**：相邻镜头的视线方向保持同象限（左镜看右，下镜的落点也在右），观众的目光不用横跳。
- 移动轨迹闭环：人物走位要「起点 → 可见运动路径 → 终点」，不许跳变。
- 场景空间快照：同一场景的多镜共用一张顶视图心智图（主要参照物 + 机位区 + 走位区），写进场景资产的 consistency 字段。

## 5. 构图（写进 description）

- 三分法/中心对称/S 形引导线/框架构图——每镜选一种主导构图并在 description 里写明。
- 景深：前景遮挡物（门缝/人群/玻璃）增加层次；特写用浅景深隔离主体。
- 留白方向：人物视线/运动方向一侧留白，制造张力或运动预期。
- 画幅适配：9:16 用纵向构图（人物占中上、地面反射占下 1/3）；2.35:1 用横向群像与大留白。

## 6. 转场与衔接（写进 description，Schema 无此字段）

```text
硬切（默认）：动作衔接切——A 镜动作进行到 60% 切 B 镜动作完成
叠化：时间流逝/情绪过渡
匹配剪辑：相似形状/动作跨场景转（车轮→太阳）
J-cut / L-cut：声音先入/延出（台词跨镜头，画面后切）
闪白/闪黑：爆点/昏迷
```

每镜 description 末尾补一行接续状态：`【接续】末帧：她攥紧的拳头松开，信纸飘落——下镜从信纸落地接起`。

## 7. 节奏设计

- **节奏密度**：单位时间镜头数 = 节奏。铺垫段 3-5s/镜，冲突段 1.5-2.5s/镜，高潮 0.8-1.5s/镜。
- **呼吸点**：每 15-20s 安排一个 ≥3s 的慢镜（空镜/特写/静场），否则观众疲劳流失。
- 15s 完播率公式：开局无废帧（20%）× 节奏呼吸（30%）× 运镜丰富（25%）× 情绪绝杀（25%）。
- 以高潮定格收尾，不设平息帧（短剧卡点原则在分镜层的落实）。

## 8. 文戏 / 武戏双模

### 文戏（对话/情绪）
- 微表情六阶段递进：触发 → 初识 → 压抑 → 泄露 → 破防 → 余韵；每阶段至少一镜承载。
- 正反打为主，插入镜头（手机屏幕/握紧的手/环境反应）切节奏。
- 金句后强制反应镜头（0.3-0.8s）。

### 武戏（动作）
- 动作分解为 11 环动力链：起手 → 蓄力 → 发劲 → 接触 → 受力 → 卸力 → 反击……每环一个可见动作。
- 接触受力三件套：命中定格 1-2 帧 + 接触点火花/尘土 + 材质震颤声。
- 防守三态：格挡、闪避、被击退——不许站着对轰。
- 混战防混淆：每个角色一套色彩锚定（服装主色/招式轨迹色/粒子色），高反差互补。
- 0-1.5s 开局硬撞（直接进交火，不绕位）；最后一帧定格。

## 9. 分镜表自检（写入画布前）

- [ ] 每镜五要素齐全，字段用词库标准词
- [ ] 每镜单一动作 + 可见终点（末帧 ≠ 首帧）
- [ ] 无相同景别+机位连排；相邻景别跳级
- [ ] 同场戏未跨轴；中全景无 90° 正侧拍
- [ ] Eye-Trace 同象限；运镜向量连续
- [ ] 台词语速核算通过；金句后有反应镜头
- [ ] 每镜 description 含构图 + 转场 + 接续状态
- [ ] 资产名称内联出现在描述的语义位置，无句尾悬空；entityRefs 与文本互相一致（shotshot-tools.md §2.5）
- [ ] 同一镜全文只有一处运镜指令，无中英混杂复述
- [ ] 跨镜实体全部有 entityRefs（无悬空引用）
- [ ] 分镜图先行：每镜有 storyboardPrompt，且画面是「进行中瞬间」而非完成态（prompt-compiler.md §12）
- [ ] 分镜图先行：finalPrompt 无画面复述——以首帧为前提只写运动与声音
